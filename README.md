# Static Website Hosting Using Amazon S3

## Project Overview
Hosted a static website using Amazon S3.

## AWS Service Used
- Amazon S3

## Project Work
- Created an Amazon S3 bucket
- Configured static website hosting
- Uploaded HTML website files
- Configured public access
- Created an S3 bucket policy
- Tested the website using the S3 website endpoint

## Technologies
- HTML
- Amazon S3
